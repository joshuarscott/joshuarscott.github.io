# Joshua Scott portfolio

Open `index.html` in a browser to preview the draft. The site has no build step or runtime dependencies.

## GitHub Pages

Place the **contents** of this directory at the repository root. In the repository's **Settings → Pages**, choose **Deploy from a branch**, select the default branch and **/ (root)**, then save. GitHub Pages is free for public repositories. For the repository named `joshuarscott.github.io`, the expected default address is https://j-scott862.github.io/joshuarscott.github.io/.

## Add media and a résumé

Put the GIFs and photos in `assets/media/`. Replace each pending media plate in `index.html` with an image using a relative path, descriptive alt text, and the image's actual width and height. Keep or update the caption to describe the finished demo. For continuously looping GIFs, provide a static poster and a user-initiated playback option, or use MP4 controls.

Once a public résumé PDF is ready, place it in `assets/media/` and link it from the About section.
